使用说明 / 弹窗被拦截怎么办
  1. 68 个打卡链接已经内置好了，登录后直接点「自动开始」或「手动逐个」即可。
  2. 要换成别的活动/链接：在输入框里按每行一条填写，支持 名称 链接 或只写链接，点「载入链接」即可（自动去重）。
  3. 自动模式：按设定间隔逐个打开新标签页，停留若干秒后自动关闭（页面自己关掉的话会立刻继续下一个）。 需要浏览器允许本页弹窗，否则会立即停下并提示。
  4. 手动模式（弹窗被拦时用）：点「手动逐个」，然后连续按 空格 打开下一个，按 S 跳过。 每次按键都是真实的用户操作，不会被拦截。
  5. 列表里每行有「打开 / ✓完成 / ↺重置」三个小按钮，可随时手动修正状态。关掉页面再打开会接着上次的进度。

自动模式需要允许弹窗：Chrome → 设置 → 隐私和安全 → 网站设置 → 弹出式窗口和重定向 → 添加允许。 推荐把这个文件放到某目录后用 python3 -m http.server 8765 起本地服务， 访问 http://localhost:8765/checkin-board.html，这样白名单好加（可以允许 localhost）。 直接双击用 file:// 打开时，Chrome 通常不给 file:// 加白名单，那就只能用手动模式。

签到依赖登录态：本工具用的是你当前浏览器的 cookie，所以务必先按顶部提示完成登录，再开始运行。 另外签到用的是同一个账号，页面停留时间别调得太短（默认 8 秒），避免请求还没打完就被关掉。
